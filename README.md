# TheDelvers

A small, turn-based trading card game that runs directly in your browser.

## Play

Open `index.html` in any modern browser. No installation, build step, or internet connection is required.

Spend Focus to play cards: attack the dungeon foes, restore health, or block incoming damage. End your turn to let the foe strike and draw another card. Defeat all four guardians to conquer the dungeon.
